# PDF Reader

Бесплатный просмотрщик и редактор PDF, который работает в браузере и устанавливается как приложение на компьютер (Windows, macOS, Linux) и телефон (Android, iPhone). Документы обрабатываются только на вашем устройстве и никуда не загружаются (единственное исключение — онлайн-перевод: по вашей команде текст страниц отправляется в Google Переводчик); после первого открытия приложение работает без интернета.

Интерфейс на русском и английском (язык выбирается автоматически, переключается в меню «⋮»).

## Возможности

**Чтение**
- непрерывная прокрутка, автомасштаб / по ширине / страница целиком / любой масштаб, Ctrl + колесо, щипок двумя пальцами на телефоне;
- миниатюры страниц, закладки (оглавление PDF), список комментариев;
- поиск по тексту с подсветкой (с учётом регистра, слово целиком) и **списком всех найденных мест** с окружающим текстом — нажатие переходит к нужному месту;
- **недавние файлы** на стартовом экране (с миниатюрой); файл открывается на той странице, где вы остановились;
- выделение и копирование текста, переход по ссылкам внутри документа и наружу;
- ночной режим чтения, тёмная/светлая тема, режим презентации, чтение вслух;
- открытие файлов, защищённых паролем.

**Пометки и редактирование**
- выделение цветом, подчёркивание, зачёркивание текста (и выделение областей на сканах); нажатие на пометку — сменить цвет или «Убрать выделение»; повторное выделение того же текста заменяет пометку, а не накладывает новую;
- карандаш, маркер, ластик, прямоугольник, овал, линия, стрелка;
- добавление текста (любые шрифты: без засечек / с засечками / моноширинный, размер, жирный, цвет);
- **изменение существующего текста** страницы: старый текст закрывается, поверх ставится новый с подобранными цветом, размером и начертанием;
- заметки-комментарии (сохраняются как настоящие комментарии PDF, видны в других программах);
- изображения, штампы («УТВЕРЖДЕНО», «ЧЕРНОВИК», дата, свой текст), подпись (нарисовать, напечатать или загрузить картинку; подписи запоминаются);
- замазка (white-out) и **безвозвратное скрытие данных** (страница со скрытыми областями превращается в изображение — текст под чёрными прямоугольниками удаляется из файла полностью);
- галочки ✔, крестики ✘ и сегодняшняя дата одним нажатием — для заполнения бумажных бланков;
- **снимок области**: обведите часть страницы — её можно скопировать, сохранить как картинку или отправить;
- выбор, перемещение, изменение размера, копирование и удаление любых пометок (в том числе прямо из списка комментариев), отмена/повтор (Ctrl+Z / Ctrl+Y).

**Перевод документа** (меню «⋮» → «Перевести документ»)
- перевод на 60+ языков, язык документа определяется автоматически; можно перевести весь документ или текущую страницу;
- **PDF с переводом**: каждый абзац заменяется прямо на странице — с тем же положением, выравниванием, цветом, жирностью и типом шрифта; картинки, таблицы и оформление остаются. Длинный перевод слегка уменьшается или занимает свободное место рядом, чтобы не наезжать на соседний текст. Исходный текст под переводом удаляется из сохранённого файла, так что копирование и поиск находят только перевод;
- исходный файл не меняется: перевод открывается как «имя-ru.pdf» и сохраняется новым файлом, а «Отменить» (Ctrl+Z) одним шагом возвращает оригинал;
- переведённые страницы на экране — такие же, как в сохранённом файле: перевод можно выделять и копировать (Ctrl+C), искать (Ctrl+F) и слушать («Читать вслух»), а любой абзац поправить инструментом «Изменить»; повторный перевод на другой язык делается с оригинала;
- **текстовый файл (.txt)** с переводом по страницам — для любых языков, в том числе китайского, японского, корейского, арабского, иврита, хинди и тайского (для них PDF с переводом недоступен: во встроенных шрифтах нет этих букв);
- переводчик: в Chrome на компьютере — **встроенный в браузер, без интернета** (текст не покидает устройство, языковой пакет скачивается один раз); в остальных случаях (приложения для Windows/macOS и Android, другие браузеры) — **Google Переводчик через интернет**, о чём диалог предупреждает до начала перевода;
- перевод можно остановить; если связь пропала посередине, уже переведённые страницы можно оставить.

**Формы**
- заполнение полей PDF-форм (текст, флажки, переключатели, списки), в том числе кириллицей;
- сохранение с заполненными полями или «фиксация» полей (делает их нередактируемыми).

**Страницы и документ**
- упорядочивание страниц перетаскиванием (мышью или долгим нажатием на телефоне), поворот, удаление, дублирование;
- вставка пустых страниц, страниц из других PDF и картинок; объединение нескольких PDF;
- извлечение выбранных страниц в новый файл, разделение документа по страницам (ZIP);
- создание PDF из картинок или пустого документа;
- водяной знак, нумерация страниц, свойства документа (заголовок, автор, тема, ключевые слова);
- защита паролем (шифрование AES-256) и права доступа (печать, копирование, редактирование);
- печать, экспорт страниц в PNG/JPEG, экспорт текста;
- **уменьшение размера файла** (для сканов и фото — в разы; показывается, сколько было и сколько стало);
- автосохранение работы на устройстве: если закрыть вкладку, можно продолжить с того же места.

## Как пользоваться

### Приложения для Windows и Android
Готовые файлы лежат на странице [Releases](https://github.com/valeratim777/Free-PDF-Reader/releases/latest):
- `PDF-Reader-Setup-<версия>.exe` — установщик для Windows (ярлыки, «Открыть с помощью» для PDF);
- `PDF-Reader-<версия>-portable.exe` — работает без установки;
- `PDF-Reader-<версия>-mac.dmg` — macOS (MacBook и iMac на Apple M1–M4 и на Intel): откройте файл и перетащите PDF Reader в «Программы»;
- `PDF-Reader-<версия>.apk` — Android.

Файлы не подписаны платным сертификатом:
- Windows покажет окно SmartScreen — «Подробнее» → «Выполнить в любом случае»;
- macOS при первом запуске скажет, что не может проверить приложение, — нажмите «Готово», откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и подтвердите паролем (один раз). Если macOS пишет, что приложение «повреждено», выполните в Терминале `xattr -cr "/Applications/PDF Reader.app"`;
- Android попросит разрешить установку из этого источника. Новая версия ставится поверх старой, данные сохраняются.

**Обновления.** Установленное приложение само сообщает о выходе новой версии (раз в 12 часов, или меню «⋮» → «Проверить обновления»). Начиная с версии 1.2.0 кнопка «Обновить» в этом сообщении сама скачивает новую версию, сверяет её контрольную сумму с опубликованной на GitHub и ставит поверх текущей:
- Windows (установщик `PDF-Reader-Setup`): обновление ставится без вопросов, программа перезапускается; открытый документ с правками можно продолжить кнопкой «Продолжить» на стартовом экране;
- Android: открывается системное окно «Обновить приложение?» — нажмите «Обновить» (в первый раз Android попросит разрешить установку из PDF Reader);
- portable-версия для Windows и macOS: кнопка «Скачать» открывает загрузку нового файла.

С версии 1.1.0 на 1.2.0 нужно обновиться один раз вручную: скачайте `PDF-Reader-Setup-1.2.0.exe` (Windows) или `PDF-Reader-1.2.0.apk` (Android) со страницы Releases и откройте — они обновят уже установленную программу, а не поставят вторую. Ваши настройки, подписи и недавние файлы сохранятся.

### В браузере
Откройте адрес, где опубликовано приложение (см. «Публикация» ниже), и нажмите «Открыть PDF» или перетащите файл в окно.

### Установить на компьютер
В Chrome или Edge откройте приложение и нажмите значок установки в адресной строке (или меню «⋮» → «Установить приложение»). После установки PDF Reader появится в меню «Пуск» / Launchpad, будет открываться в отдельном окне и предлагаться в «Открыть с помощью» для PDF-файлов. В Chrome/Edge кнопка «Сохранить» записывает изменения прямо в исходный файл.

### Установить на телефон
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран». После установки PDF Reader появится в списке «Поделиться» — можно отправлять в него PDF из почты, мессенджеров и файлового менеджера.
- **iPhone/iPad (Safari):** кнопка «Поделиться» → «На экран „Домой“».

На телефоне инструменты находятся внизу экрана, рисовать можно пальцем или стилусом, страница масштабируется щипком, прокручивается двумя пальцами в режиме рисования. Сохранённый файл можно сразу отправить через меню «⋮» → «Поделиться».

### Интерфейс
- **Верхняя панель:** файл, переход по страницам, масштаб, поиск, отмена/повтор, печать, справка и главная кнопка «Сохранить». Остальное — в меню «⋮», разбитом на разделы «Файл», «Документ» (в том числе «Перевести документ»), «Вид», «Справка и настройки».
- **Панель инструментов** (на телефоне — внизу экрана) с подписями: Выбор, Выделить, Заметка, Текст, Изменить, Карандаш, Фигуры, Подпись, Вставить, Скрыть, Страницы. Стрелочка ▾ у кнопки — повторное нажатие открывает варианты (например, «Фигуры» → прямоугольник, овал, линия, стрелка).
- **Контекстная панель** под инструментами показывает настройки выбранного инструмента (цвет, толщина, прозрачность, шрифт) и короткую подсказку, что делать; «Готово» возвращает к «Выбору».
- **У выбранной пометки** появляются кнопки «Изменить», «Дублировать», «Удалить»; углы тянутся для изменения размера.
- **Справка** (клавиша `?` или меню «⋮» → «Справка») описывает все инструменты, жесты и горячие клавиши.

### Горячие клавиши
| Клавиши | Действие |
| --- | --- |
| V, H, G, L, N, T, E, P, M, X, R, A, S, I, W | инструменты: выбор, рука, снимок области, выделение, заметка, текст, изменить текст, карандаш, маркер, ластик, прямоугольник, стрелка, подпись, изображение, замазка |
| ? | справка |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | открыть / сохранить / сохранить как |
| Ctrl+P | печать |
| Ctrl+F | поиск |
| Ctrl+Z / Ctrl+Y | отменить / повторить |
| Ctrl + колесо, Ctrl+= / Ctrl+− / Ctrl+0 | масштаб |
| Delete, стрелки, Ctrl+D | удалить, сдвинуть, дублировать выбранную пометку |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать, вырезать, вставить выбранную пометку (выделенный текст копируется как обычно); вставить картинку из буфера обмена |
| Esc | снять выбор / вернуться к инструменту «Выбор» |

Сочетания работают при любой раскладке клавиатуры (в том числе русской).

## Разработка

Нужен Node.js 20+.

```bash
npm install
npm run dev        # локальный сервер разработки (http://localhost:5173)
npm test           # автотесты (сохранение PDF, формы, шифрование, геометрия)
npm run build      # сборка в папку dist/
npm run preview    # просмотр собранной версии
```

Папка `dist/` — готовый статический сайт: его можно выложить на любой хостинг (GitHub Pages, Netlify, Vercel, свой сервер). Для установки как приложения нужен HTTPS (или localhost).

### Устройство проекта
- `src/viewer/` — отображение страниц (pdf.js), текстовый слой, формы, жесты;
- `src/annotations/` — инструменты и отрисовка пометок;
- `src/export/exporter.ts` — запись итогового PDF (pdf-lib): порядок и поворот страниц, пометки, формы, водяной знак, нумерация, скрытие данных, шифрование;
- `src/features/` — открытие/сохранение, печать, экспорт, подписи и штампы, автосохранение сессии, диалог перевода (`translate.ts`);
- `src/translate/` — перевод: разбиение текста страницы на строки и абзацы и подгонка перевода в их место (`layout.ts`), сервисы перевода (`engines.ts`), список языков;
- `src/export/stripText.ts` — удаление исходного текста под переведёнными абзацами при сохранении;
- `src/ui/` — панели, меню, диалоги, упорядочивание страниц, поиск;
- `public/sw.js`, `public/manifest.webmanifest` — работа без интернета, установка, «Открыть с помощью» и «Поделиться».

Все пометки хранятся в координатах PDF-страницы, поэтому то, что видно на экране, совпадает с сохранённым файлом при любом повороте и масштабе.

## Публикация на GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`. Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. После каждого push в ветку `main` приложение будет опубликовано по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`. (Для приватных репозиториев GitHub Pages доступен на платных тарифах.)

## Правовые моменты

- Весь код приложения написан с нуля; он не основан на коде Adobe и не копирует его.
- Формат PDF — открытый международный стандарт ISO 32000, работать с ним может кто угодно.
- Используются только библиотеки с открытыми лицензиями, разрешающими коммерческое и личное использование (список ниже). При распространении приложения сохраняйте их уведомления об авторских правах — они перечислены в `THIRD_PARTY_NOTICES.md` и в окне «О программе».
- В названии, интерфейсе и иконках не используются товарные знаки Adobe (Adobe, Acrobat, логотипы). Не добавляйте их, если будете переименовывать приложение.
- Онлайн-перевод обращается к общедоступному адресу Google Переводчика (`translate.googleapis.com`), которым пользуются многие бесплатные программы. Это не платный API с гарантиями: Google может ограничивать число запросов или изменить его работу. Встроенный переводчик Chrome работает без этого сервиса.

## Чего пока нет

- распознавание текста на сканах (OCR) — поэтому и перевести скан нельзя;
- PDF с переводом на языки с иероглифами, арабским письмом, ивритом, деванагари и тайским (для них есть перевод в .txt);
- цифровые подписи с сертификатом (ЭЦП) — сейчас подпись ставится как изображение;
- перекомпоновка абзацев при правке текста (правка заменяет отдельную строку/фрагмент);
- формы XFA и JavaScript-логика внутри форм;
- сравнение документов и конвертация в Word/Excel.
