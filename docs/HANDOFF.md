## Готово к выпуску: версия 1.3.0 — новое «Читать вслух»

В этой ветке, PR в `main` ещё не влит:
- `src/features/readAloud.ts` — чтение по абзацам с текущей страницы, язык определяется для каждого абзаца (`src/speech/lang.ts`), подсветка читаемого абзаца, выбор голоса в панели (запоминается для каждого языка), скорость, пауза. Читает показанную страницу, то есть перевод, если он есть; на переведённой странице порядок абзацев берётся из оригинала.
- Компьютер и браузер: нейросетевые голоса Piper, синтез на устройстве в Web Worker (`src/speech/piperWorker.ts`, `src/speech/neural.ts`). Движок (ONNX Runtime + фонемизатор eSpeak NG, ~29 МБ) лежит в `public/speech/` (копирует `scripts/copy-assets.mjs`), голоса скачиваются при первом использовании с Hugging Face (фиксированная ревизия, `src/speech/catalog.ts`) и хранятся в Cache Storage. Голоса: ru — Дмитрий, Денис; uk — Тетяна, Микита, Лада (одна модель `uk_UA-ukrainian_tts-medium`, 77 МБ); en — Kristin, John; es — Sharvard (жен./муж.), Davefx. Если у системы есть голоса «Natural/Online» (Edge), они идут первыми.
- **Украинская модель читает буквы, а не фонемы** (`"phoneme_type": "text"` в её `.onnx.json`). Раньше ей подавались фонемы eSpeak — получалась бессмыслица (это и была «несвязная Тетяна»). Теперь `src/speech/letters.ts` готовит буквы как Piper (нижний регистр, NFD, таблица `phoneme_id_map` модели), а `src/speech/numbers.ts` пишет числа словами (такая модель цифры пропускает). Отдельные `uk_UA-*-high` убраны: 114 МБ каждая и в ~6 раз медленнее (не успевали за чтением), а разборчивость не лучше.
- Android: свой плагин `SpeechPlugin.java` (системный синтез речи телефона, обычно Google), в APK движок Piper не попадает (`scripts/trim-android.mjs`, шаг в `apps.yml`). В манифест добавлен `<queries>` для TTS_SERVICE.
- Версия 1.3.0 (`package.json`), заметки к выпуску — `.github/release-notes.md`, раздел «Чтение вслух» в README.

Проверено (4 ноября 2026):
- Разборчивость — распознаванием речи (faster-whisper medium, сравнение с исходным текстом): украинская модель до исправления — 100 % ошибок в словах, после — Микита ~0, Тетяна 2, Лада 3 ошибки на 30 слов (у high-моделей было 2–4); ru/en/es — без ошибок (кроме цифр вместо слов в распознанном тексте).
- Сквозная проверка в браузере (Playwright): украинский PDF → «⋮» → «Читать вслух»; первая фраза через ~8 с (загрузка модели из кэша), дальше фразы идут без пауз.
- Windows-приложение (Electron под Xvfb, схема `app://`): Web Worker, скачивание голоса с прогрессом и Cache Storage работают, кэш сохраняется между запусками; украинский и русский (eSpeak, `.wasm`/`.data` по `app://`) голоса синтезируются; через меню читает, абзац подсвечивается. Hugging Face отдаёт CORS-заголовки и для `app://pdf-reader`.

Как это проверялось (скрипты не в репозитории): синтез — сообщения `speak` прямо в собранный `dist/assets/piperWorker-*.js` со страницы `vite preview`, модели раздавал локальный сервер с CORS; сквозная — патч `AudioBuffer.prototype.copyToChannel` в Playwright, затем WAV; голос заранее кладётся в кэш `pr-voices-v1` под адресом Hugging Face. Electron: `node node_modules/electron/install.js`, затем `_electron.launch` из Playwright под `xvfb-run`, PDF передаётся аргументом командной строки.

Осталось:
1. Проверить на настоящем Android-телефоне `SpeechPlugin` (не запускался вживую; собирается: `./gradlew assembleDebug`).
2. Влить PR в `main`, затем Actions → «Build apps» → Run workflow на `main`.

## Как проверить локально

```
npm ci
npm run typecheck && npm test && npm run build
npx vite preview --port 4173
```
Перевод в тестах подменяется (Google из облачных сред отвечает 429). Android: `npm run android` (нужен Android SDK); Maven Central из облака может отвечать 429 — помогает init-скрипт Gradle с зеркалом `maven-central.storage-download.googleapis.com`.
